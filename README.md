# robojepa.github.io

Project page for **RoboJEPA: Scaling Robotic Latent World Models**. It's a static site served by GitHub Pages from `main`.

- `index.html`, `style.css`, `main.js`: the page (cover panel over a background video, abstract, visual abstract)
- `media/bg_{landscape,portrait}.mp4`: the 25 s background loop (desktop and phone). It shows RoboJEPA-8B imaginations:
  first the three-view DROID clip, then a mosaic of 8B imaginations from many robots.
- `media/visual_abstract.svg` and `media/va_panel{1,2,3}.png`: the paper's visual abstract (full figure for wide screens,
  stacked panels for phones)

Code: https://github.com/facebookresearch/robo_jepa
